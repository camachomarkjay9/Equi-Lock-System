About EquiLock

  1. You must register with EquiLock using the QR code before using the kiosk.
  2. We record your name, email and ID for security only. This information will not be shared.
  3. If you borrow damaged equipment, report it on the Condition Page and alert the admin. If no admin is present, return it immediately.
  4. If you damage any equipment, submit a report and notify the admin right away.
  5. If you finish using the equipment early, return it immediately. Do not let anyone else borrow it, as the record is in your name. You will be responsible for any damage.
  6. Use all borrowed equipment responsibly and handle with care.
  7. Return equipment on or before 4 hours. Late returns will result in a 1-week ban from using the kiosk.
